## 📌 About

**ValyaR Mod Analyzer** is a Minecraft Java **SSing tool** designed for **SSers** to inspect a player's mods folder and identify cheats, Ghost Clients, suspicious code, obfuscation, bypass indicators, and deleted-mod traces.

---

## ✨ Features

* 🔍 **Deep Mod Scanning** — analyzes Minecraft `.jar` mods and nested JARs
* 🧬 **Cheat Detection** — detects cheat mods, Ghost Clients, and suspicious components
* 🕵️ **Forensics** — checks obfuscation, bypass indicators, JVM injection, and system traces
* 🗑️ **Deleted Mod Detection** — searches for traces of previously removed mods
* 🧠 **JVM & Memory Analysis** — analyzes Java-related system indicators
* 📋 **MC Log Analysis** — searches Minecraft logs for relevant findings
* 📊 **Weighted Verdicts** — scores findings based on their severity
* 📄 **HTML Reports** — generates detailed reports for SS investigations
* 🌍 **Bilingual UI** — English & العربية
* 🖥️ **Dark Interface** — black, white, and blood-red design

---

## 🚨 Verdicts

|      Status     | Meaning                              |
| :-------------: | ------------------------------------ |
| 🔴 **CRITICAL** | Strong cheat or security indicators  |
|  🟥 **FLAGGED** | Suspicious or cheat-related findings |
|  🟡 **REVIEW**  | Requires further investigation       |
|   🟢 **CLEAN**  | No significant findings              |
| 🔵 **VERIFIED** | Matches a trusted mod fingerprint    |

## 🛠️ Detection Engines

ValyaR Mod Analyzer combines multiple detection engines:

```text
Verify
ModScan
Doomsday
Dqrkis
Bypass
Obfuscation
JVM
Memory + System
```

These engines inspect mod contents, classes, strings, fingerprints, JVM arguments, memory, and system-level indicators.

## 🖥️ Requirements

* Windows 10 / 11
* x64

The standalone version is distributed as a **single executable** and does not require a separate .NET installation.

---

## 📥 Usage

1. Open **ValyaR Mod Analyzer**
2. Select or auto-detect the Minecraft mods folder
3. Click **START SCAN**
4. Review the detected mods and findings
5. Generate an **HTML Report** if needed

---

## ⚠️ Disclaimer

ValyaR Mod Analyzer is designed for **Minecraft server protection, SSing, security research, and educational purposes**.

Detection is heuristic and signature-based. False positives and false negatives are possible.

**Always review the detected reasons and the complete SS evidence before taking action against a player.**
